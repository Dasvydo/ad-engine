# research/media

Hand-saved ad creatives, one per candidate, named after the candidate id:
`fb-<library id>.mp4` (or `.mov`, `.m4v`, `.webm`, `.jpg`, `.jpeg`, `.png`,
`.webp`). Nothing in this repository downloads one; an operator opens the ad's
snapshot URL and saves the file. Everything here except this file is
gitignored - it is somebody else's creative.
